# Agent SNR future-world pitch and demo

## Story premise

People are beginning to delegate browsing, comparison, and shopping to personal agents. Websites are becoming executable interfaces for those agents. A successful tool call proves that the interface worked, but it does not tell the site owner what the person wanted, why the agent changed course, or whether the journey produced a useful outcome.

Agent SNR is the WordPress operations layer for that world. It connects WebMCP activity to privacy-safe journey evidence, direct agent feedback, human checkpoints, verified commerce outcomes, and owner decisions.

## Causal chain

Shopper intent → WebMCP action → unmet demand → agent recovery → human order → owner-agent investigation → inventory decision

Every beat in the video must advance this chain. Session governance remains in the product and full deck, but it is removed from the demo ending because it does not resolve the shopper's IPX5 constraint.

## Transition rules

- Use one warm-white visual system for every context card.
- Use 450–600 ms dissolves. No hard cuts between pitch cards.
- Put one complete spoken thought on each card.
- Start speech after a 300–450 ms visual hold and finish 400–700 ms before the outgoing dissolve.
- The solution card contains the exact first live frame so the transition becomes a match dissolve.
- Trim both the replaced source video and source audio. Never retain narration written for discarded footage.
- Keep natural narration between 0.97× and 1.03×. Rewrite lines that do not fit; pad with a short pause instead of slowing speech.
- Cue live narration after the prompt, call, result, or persona state becomes visible.
- End on the live product and real owner opportunity, with branding introduced over the existing UI rather than a detached closing slide.

## Acceptance criteria

- [x] The working product appears in the first frame as a cold open and again before 15 seconds.
- [x] A first-time viewer can explain the future world, owner blind spot, Agent SNR, shopper story, and owner decision.
- [x] No visual transition occurs mid-sentence.
- [x] Every spoken tool/result claim is already visible or appears on the named beat.
- [x] The final action resolves the demonstrated missed-demand story.
- [x] The full video remains below three minutes with natural audio, no music, and no prohibited third-party media.
