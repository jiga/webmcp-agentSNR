# Changelog

All notable changes are documented here. This project follows semantic versioning for plugin releases.

## [Unreleased]

- Public links, real-client results, formal trademark/domain clearance, and release provenance remain to be added before submission.
- Added a human-readable Agent Guide, automatic privacy-preserving opportunity signals, structured evidence-linked agent feedback, server-computed measurements, and explicit site-observed/agent-reported/site-verified provenance in Agent SNR.
- Upgraded Agent Guide 1.1 with explicit co-browsing scope, shopper/operator journeys, trust effects, zero Sensitive Actions, optional feedback, and the subtotal/final-total boundary.
- Reduced public discovery to 12 storefront and 8 Agent SNR tools by hiding two legacy gap abilities, and renamed the non-purchasing action to `prepare_checkout_handoff`.
- Added pinned GoogleChromeLabs WebMCP Evals schemas, selection and browser fixtures, an application-error-aware native smoke gate, provenance-bound report checking, and Workbench/directory release handoffs.
- Preserved object-based third-party WooCommerce gateways when registering the demo gateway, preventing admin fatals with extensions such as WooCommerce PayPal Payments.
- Bounded Agent Sessions replays beneath the existing tool-output ceiling, preserving first/latest and diagnostic evidence while making row loading and failures explicit.
- Hydrated and synchronized the accessible storefront cart badge across existing and newly opened tabs through private manifest snapshots, without adding session state to cacheable HTML.
- Reframed the monitoring surface around Agent Sessions, Workflow Replay, Signals, Tools, Outcomes, and Controls.
- Adopted **Agent SNR** as the public brand with the descriptor “Agent outcome monitoring for WordPress,” while preserving internal compatibility identifiers.
