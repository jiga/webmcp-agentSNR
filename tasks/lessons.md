# Project lessons

- Treat Docker Compose and other shared long-lived services as globally owned state in multi-agent work. Before starting, recreating, stopping, or rebinding a shared stack, coordinate with the root agent; prefer non-mutating source/static checks when ownership is not explicit.
- After any WebMCP cart mutation, verify every shared cart indicator—not only the detailed cart panel. Keep the workflow panel, header badge, accessible label, and checkout state synchronized from the same authoritative cart result, with browser coverage for the complete visible update.
- For every clickable workflow row, test the largest realistic replay—not only short fixtures. Bound server payloads before the transport limit, disclose truncation in the UI, and surface a visible row-level error instead of leaving an action that appears to do nothing.
- Treat WooCommerce extension filters as heterogeneous integration boundaries. Preserve third-party keys and object instances, avoid string-only whole-array transforms such as default `array_unique()`, and regression-test mixed class-string/object inputs with representative payment extensions.
- When a shopper explicitly asks the agent to follow the Agent Guide's feedback instructions, the intended Agent SNR behavior is automatic submission of bounded, non-sensitive, same-workflow structured feedback. Distinguish any browser-platform confirmation requirement from the product UX; do not present that pause as an Agent SNR requirement.
- Treat third-party eval harness success as untrusted at the application boundary. Reproduce application failure envelopes in package-contract tests, require positive result constraints, bind reports to the exact fixture/model/run provenance, and keep one strict release threshold across code and documentation.
- Bind eval evidence to mode-specific runtime configuration as well as fixture/model/runs, and validate reported expectations against the authored ordered/unordered tree. A set-equivalent trajectory is not proof that an ordered workflow ran correctly.
- Prime one stable Woo guest cookie during storefront bootstrap before parallel first-touch tools can run; cookie priming must not recalculate totals or write cart contents on a read-only manifest request.
- When natural-language search repeats structured price or attribute constraints, remove only phrases whose values are still enforced. Combine textual and structured price bounds conservatively so a looser field can never weaken the shopper's stated budget.
- For one-decision model evals, disable provider parallel tool calls and bind that setting into report provenance. Do not make duplicate real calls pass merely to accommodate provider variance.
